# ECG Lab roadmap

This sequence keeps measurement and rendering reliability ahead of additional learning features.

1. **Calibration hardening — complete.** Shared time/voltage transforms, pulse, viewport extents, 12-lead alignment and unit tests are documented in `ECG_CALIBRATION.md` and `LEAD_SYSTEM.md`.
2. **Browser regression suite — complete.** Five Chromium scenarios cover startup, all leads, machine controls, manual intervals, theme state/colors, calibration pulse, aligned 12-lead x coordinates and responsive scrolling. The first GitHub Actions run for this checkpoint passed dependency install, browser setup, unit tests, type-check, build and browser tests.
3. **Accessibility and content governance — complete for this focused checkpoint.** Browser keyboard/semantic regressions, six-state axe scans, responsive order correction, typed content/provenance schemas, runtime validation, publication gates, draft fixtures, and workflow documentation are in place. This is not a full WCAG audit or clinical review.
4. **First Learn milestone — framework implemented; content release awaiting review.** The 16-topic curriculum plan, three authored draft lessons/checks, validated registry-backed catalog, reusable renderer, shared-engine demonstrations, formative knowledge checks, accessibility interactions, and local versioned progress exist. The catalog correctly remains empty until actual source, educational, medical, and publication review evidence is supplied for the current content versions. Indian MBBS/CBME source mapping is not yet established. See `LEARN_CURRICULUM.md` and `SESSION_CHECKPOINT.md`.
5. **Practice questions.** Add deterministic answer keys and explanations sourced through the reference model; do not place clinical facts in UI components.
6. **Exam mode.** Add only after question lifecycle, scoring, versioning, and accessibility behavior are specified and tested.
7. **Expert-reviewed case workflow.** Introduce clinical ECG cases only when provenance, licensing/authorization, required technical metadata, medical review, and publication approval are real and recorded.
8. **Integration boundary.** Stabilize a typed embeddable API and verify it in a separate KYP integration task; do not modify KYP production during standalone work.
9. **Optional export and signal artifacts.** Defer physical-size export, noise/artifact controls, and import pipelines until core browser and calibration tests are stable.
10. **Live paper-sweep checkpoint — implemented and regression-tested.** The simulator now has a monotonic time-based clock, bounded rolling SVG windows, shared lead timing, reduced-motion default pause, and accessible playback controls. See `ARCHITECTURE.md`, `QA_REPORT.md`, and the current `SESSION_CHECKPOINT.md`. This is still a synthetic educational model, not a clinical monitor.
11. **Moving-strip manual measurement UX — implemented and remote-verified.** Absolute timestamps remain authoritative; visible trace clicks place the selected point, numeric fields remain the keyboard alternative, and off-window points are reported as before/after rather than moved. Reset restores the selected measurement's example points while preserving playback state. The corrected remote feature commit `e266dfbe276172888ff04ca39e9c45e5425983d9` passed Actions `39344966547`. See `ARCHITECTURE.md` and the ECG-CP7 QA entry.
12. **Content review readiness — narrowed, not approved.** Lesson 3 and its linked check are version `0.4.0` and now discuss simulator logical coordinates only. Candidate source locations for general paper/gain claims could not be fully verified, so those claims and references were removed from this lesson. All lessons/checks remain drafts; no source, rights, educational, medical, or publication approvals were invented. Next: collect genuine review input for the exact current content versions and continue claim-by-claim source checking.
13. **Measurement workspace foundations — implemented locally.** Named manual measurement sets support selection, keyboard operation and deletion without changing source samples. Optional learner notes are separately typed timeline annotations; a future authored teaching region requires an explicit content ID, semantic role and version. Notes map from absolute time through the existing rolling calibration transform and intentionally render once in 12-lead view. A strict version-1 experiment snapshot now validates supported settings, playback intent/time, measurements and annotations before any persistence. No save/restore, guided experiment, clinical annotation or authored annotation has been released.

14. **Local save/restore and guided exercises (release 1) - implemented locally, draft content.** The clock has a validated seek/restore API; versioned snapshots save and restore locally; four unreviewed draft exercises (R-R interval, gain invariance, cross-lead beat matching, paper speed and grid) validate marker times against the signal model's own event times and keep versioned local progress. Not published, not reviewed, not CI-verified. See `IMPLEMENTATION_LEDGER.md` (ECG-STATE-09, ECG-EXERCISE-10).

No phase may describe the synthetic morphologies as clinically validated without evidence and review.

## Long-horizon build sequence

Continue from task 026 with a tested clock seek and supported local save/restore, then guided calibration/lead/grid exercises. Case simulation, medication content, formal assessments, gamification, and KYP integration remain later milestones; none are implemented by this roadmap note.
